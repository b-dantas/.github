# .github

Arquivos padrão de comunidade da conta `b-dantas`. Os templates de issue em
`.github/ISSUE_TEMPLATE/` valem para todo repositório desta conta que não tenha
os seus próprios.

Os templates usam só as labels que o GitHub cria por padrão (`bug`,
`enhancement`, `documentation`). Convenções específicas de um projeto
(labels extras, comandos de verificação, pastas) ficam no repositório dele.
